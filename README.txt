Интеллектуальная система прогнозирования стоимости жилой недвижимости Москвы

Программный комплекс на Python для автоматизированного прогнозирования цен на квартиры с использованием методов регрессионного анализа и машинного обучения.

Ключевые возможности:
- Множественная линейная регрессия (OLS) с полной эконометрической диагностикой
- Регуляризованные модели (Ridge, Lasso, Elastic Net)
- Полиномиальная регрессия (степени 2 и 3)
- Ансамблевые алгоритмы: Random Forest, CatBoost
- Автоматический отбор признаков и итеративное улучшение модели
- Графический интерфейс (Tkinter) для ручного прогнозирования
- Генерация детализированных текстовых отчётов и визуализаций

как запустить:
создать изолированную среду (по желанию)
python -m venv venv
venv\Scripts\activate



установить зависимости
pip install -r requirements.txt




расположите папки около файла .py в таком формате (если не понятно запустите программу и она сама создаст папки но выдаст ошибку из-за пустого input_data)
project/
├── input_data/          # Поместите сюда CSV-файл с данными
├── out_data/           # Сюда будут сохранены отчёты и графики
│   ├── text/          # Текстовые отчёты (.txt)
│   └── visualizations/ # Графики (.png)
├── apartment_analysis.py
└── requirements.txt

Запустите программу средой исполнения или через терминал
python apartment_analysis.py
