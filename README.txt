Интеллектуальная система прогнозирования стоимости жилой недвижимости Москвы

Программный комплекс на Python для автоматизированного прогнозирования цен на квартиры с использованием методов регрессионного анализа и машинного обучения.

Ключевые возможности:
- Множественная линейная регрессия (OLS) с полной эконометрической диагностикой
- Регуляризованные модели (Ridge, Lasso, Elastic Net)
- Полиномиальная регрессия (степени 2 и 3)
- Ансамблевые алгоритмы: Random Forest, CatBoost
- Автоматический отбор признаков и итеративное улучшение модели
- Графический интерфейс (Tkinter) для ручного прогнозирования
- Генерация детализированных текстовых отчётов и визуализаций

как запустить:
создать изолированную среду (по желанию)
python -m venv venv
venv\Scripts\activate



установить зависимости
pip install -r requirements.txt




расположите папки около файла .py в таком формате (если не понятно запустите программу и она сама создаст папки но выдаст ошибку из-за пустого input_data)
project/
├── input_data/          # Поместите сюда CSV-файл с данными
├── out_data/           # Сюда будут сохранены отчёты и графики
│   ├── text/          # Текстовые отчёты (.txt)
│   └── visualizations/ # Графики (.png)
├── apartment_analysis.py
└── requirements.txt

Запустите программу средой исполнения или через терминал
python apartment_analysis.py


возможности настройки конфига 

DATA_PATH_INPUT — относительный путь к директории с исходными данными.
DATA_PATH_OUTPUT — относительный путь к директории для сохранения результатов работы. 
TARGET_COL — имя столбца в исходном датасете, который выступает в роли целевой переменной для прогнозирования.
TEST_SIZE — доля данных, выделяемая для формирования тестовой выборки при разделении датасета.
RANDOM_STATE — фиксированное значение для инициализации генератора случайных чисел.
DROP_FEATURES — список имён колонок, которые исключаются из признакового пространства перед обучением моделей.
ALPHA — уровень статистической значимости, используемый при проверке гипотез в эконометрической диагностике.
CORR_THRESHOLD — пороговое значение модуля коэффициента парной корреляции Пирсона для автоматического выявления коллинеарных пар признаков.
VIF_THRESHOLD — критическое значение фактора инфляции дисперсии. если у признака VIF больше этого порога у фактора признается критическая мультиколлениарность с каким-то другим
COOKS_FACTOR — множитель, используемый для расчёта порога значимости расстояния Кука (Cook's Distance).
priority_threshold — уровень строгости при автоматическом аудите и селекции признаков. Принимает значения от 1 до 3
APARTMENT_INDEX — индекс объекта в тестовой выборке, используемый для демонстрации работы функции точечного прогнозирования с расчётом доверительных интервалов. 



также в input_data в теории можно поместить свой датасэт и почти ничего не сломается (нужно будет только таргет поменять в конфиге)
